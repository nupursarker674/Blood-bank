# 🩸 Blood Bank Management System

A Java Swing and MySQL based desktop application for managing blood donor information.

## Features
- Admin Login
- Add Donor
- Update Donor
- Delete Donor
- Search by Blood Group
- View Total Donors
- MySQL Database Integration

## Technologies Used
- Java
- Swing
- JDBC
- MySQL
- XAMPP

## Database
Database Name: `bloodbank`

Table: `donors`

## Default Login
Username: `admin`

Password: `1234`

## How to Run
1. Clone the repository.
2. Create the `bloodbank` database.
3. Import the `donors` table.
4. Add MySQL JDBC Driver.
5. Run `BloodApp.java`.
